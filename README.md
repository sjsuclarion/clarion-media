# CLARION Media

GitHub-ready media library for the CLARION Social Media Repository.

Each issue folder contains:
- one folder per Instagram post
- numbered carousel slides (`01.webp`, `02.webp`, etc.)
- `caption.webp` when a caption screenshot was provided
- `manifest.json` listing the post folders and files

These predictable paths are intended for lightweight Google Sites galleries that reference GitHub Pages URLs instead of embedding image data inside the HTML.
